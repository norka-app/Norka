# Флаги функций

Каждая новая возможность Norka включается флагом. Без флага её не добавляют.

Флаги собраны в `internal/features`. У каждого стабильный `id`, значение по умолчанию и два ключа перевода: название и одна строка описания. Состояние лежит в таблице `[features]` файла `config.toml`.

```toml
[features]
profiles = false
quick_search = true
```

Нет ключа — берётся значение по умолчанию. Поэтому старый `config.toml` открывается как раньше. Явное `false` записывается и не подменяется умолчанием при следующей загрузке.

Интерфейс читает флаги через `useFeature('id')` (`frontend/src/features/feature-store.js`). Бэкенд шлёт их методом `GetFeatures` и событием `features:changed`, так что блок появляется и прячется без перезапуска. Выключенная возможность не просто скрыта: не регистрируется её горячая клавиша, не показывается пункт трея и не идёт фоновая работа.

Сейчас в каталоге: профили (по умолчанию выключены), быстрый поиск, уведомления, проверка обновлений, мониторинг трафика, анимации норки, команда SSH (по умолчанию включена). Уведомления и мониторинг трафика забрали прежние переключатели, второго рядом нет. Язык интерфейса и хранение паролей в связке ключей флагами не являются.

Выключение профилей не удаляет сохранённые профили и не останавливает уже запущенные туннели.

## Как добавить флаг

1. В `internal/features` добавьте константу `ID` и строку в `All`: id, значение по умолчанию, `TitleKey`, `DescriptionKey`.
2. Те же ключи положите в `frontend/src/locales/ru.json` и `en.json`. Набор ключей и плейсхолдеры вида `{name}` должны совпадать, иначе упадёт `internal/i18ncheck`.
3. В интерфейсе завяжите показ на `useFeature('id')`. Отдельный переключатель в настройках не нужен: секция «Функции» строится из каталога.
4. В бэкенде проверьте флаг до фоновой работы, горячей клавиши и пункта трея. Выключение не должно стирать данные пользователя.
5. Если у возможности уже был свой on/off, перенесите его в реестр и оставьте текущее значение пользователя. Два переключателя на одно и то же не показывайте.
6. Допишите тест: значение по умолчанию, отсутствие ключа, явное `false` после сохранения и загрузки.

Пользователь включает флаг в **Настройки → Функции**.
