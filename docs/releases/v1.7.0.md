## Русский

Конфиг теперь можно импортировать, перетащив файл .toml в окно Norka.

## Новое

- **Импорт перетаскиванием.** Перетащите `config.toml` в окно, и Norka запустит тот же импорт, что и кнопка «Импорт» в настройках, с подтверждением. Работает в простом и расширенном режимах. Пока файл над окном, видна панель с пунктирной рамкой. На файл другого типа или на несколько файлов сразу Norka отвечает подсказкой и ничего не меняет.

## Установка

- Каждый тег теперь сам публикует Norka в Homebrew и Scoop.
- Образцы winget, Scoop и Homebrew в `packaging/` обновлены до 1.6.1. Этот выпуск их не меняет. После тега `v1.7.0` workflow `update-manifests` возьмёт версию и хеши из `SHA256SUMS` и откроет отдельный pull request.

## Как обновиться

- **С 1.6.x:** на Windows и macOS нажмите «Обновить и перезапустить». На Linux кнопка «Скачать» открывает ссылку в браузере: программа сама себя не заменяет.
- **Windows:** если обновление в один клик недоступно, закройте Norka и замените старый `norka.exe` новым.
- **macOS:** откройте `norka.dmg` и перетащите Norka в «Программы» с заменой.
- **Linux:** скачайте AppImage, `.deb` или `.tar.gz`, что вам удобнее.

Туннели и настройки сохраняются.

**Полный список изменений:** https://github.com/norka-app/Norka/compare/v1.6.1...v1.7.0

## English

You can now import a config by dropping a .toml file onto the Norka window.

## New

- **Drag-and-drop import.** Drop `config.toml` onto the window and Norka runs the same import as the Import button in settings, with the same confirmation. It works in both simple and advanced mode. While the file is over the window, a panel with a dashed border shows. If the file has a different type, or you drop several files at once, Norka shows a hint and changes nothing.

## Installation

- Every tag now publishes Norka to Homebrew and Scoop.
- The winget, Scoop, and Homebrew samples in `packaging/` are updated to 1.6.1. This release leaves them as they are. After the `v1.7.0` tag, the `update-manifests` workflow takes the version and hashes from `SHA256SUMS` and opens a separate pull request.

## How to update

- **From 1.6.x:** on Windows and macOS press "Update and restart". On Linux, "Download" opens the file in the browser: the app does not replace itself.
- **Windows:** if the one-click update is unavailable, quit Norka and replace the old `norka.exe`.
- **macOS:** open `norka.dmg` and drag Norka into Applications, replacing the previous copy.
- **Linux:** download the AppImage, `.deb`, or `.tar.gz`, whichever you prefer.

Tunnels and settings are kept.

**Full changelog:** https://github.com/norka-app/Norka/compare/v1.6.1...v1.7.0
