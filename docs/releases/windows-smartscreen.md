## Windows: неизвестный издатель

`norka.exe` со страницы выпуска не подписан. SmartScreen показывает предупреждение и пишет, что издатель неизвестен. Нажмите **Подробнее**, затем **Выполнить в любом случае**.

Сверить хеш с этим выпуском (строка должна совпасть с `norka.exe` в `SHA256SUMS`):

```bat
certutil -hashfile norka.exe SHA256
```

Проверить, что файл собран в этом репозитории:

```bash
gh attestation verify norka.exe --repo norka-app/Norka
```

Установка через winget или Scoop обычно проходит без этого предупреждения.
