На Windows обновление больше не открывает пачку чёрных окон командной строки.

## Исправления

- **Быстрый поиск открывается стабильно и на любой раскладке.** Глобальное сочетание на Windows больше не срабатывает через раз, а Ctrl+K в окне работает и с русской клавиатурой.
- **Обновление на Windows больше не показывает окна `cmd`.** Новая версия запускается напрямую и сама дожидается, пока закроется предыдущая. Окна `find`, `tasklist` и `ping` при этом не появляются.
- При старте Norka убирает из временной папки оставшиеся файлы `norka-relaunch-*.cmd`.
- Открытие папки с настройками, проверка связи и диагностика SSH на Windows тоже не мелькают консольным окном.

## Как обновиться

- **С 1.2.0:** на Windows и macOS нажмите «Обновить и перезапустить». При обновлении с 1.2.0 окна ещё могут мелькнуть в последний раз, их можно просто закрыть. На Linux кнопка «Скачать» открывает ссылку в браузере: программа сама себя не заменяет.
- **Windows:** если обновление в один клик недоступно, закройте Norka и замените старый `norka.exe` новым.
- **macOS:** откройте `norka.dmg` и перетащите Norka в «Программы» с заменой.
- **Linux:** скачайте AppImage, `.deb` или `.tar.gz`, что вам удобнее.

Туннели и настройки сохраняются.
