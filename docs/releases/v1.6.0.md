Туннели могут работать без открытого окна. Для этого в Настройки → Функции включите «Фоновый режим».

## Новое

- **Фоновый режим.** Окно подключается к `norkad`. Закрытие окна туннели не останавливает. В трее появляется «Выйти и остановить туннели».
- **Настройки.** В Настройки → Общие видны статус фонового процесса, кнопка «Остановить фоновый процесс» и переключатель «Запускать при входе в систему». Права администратора не нужны.
- **Пароль.** Демон сам пароль не спрашивает. Если туннель с паролем запускает уже открытое окно, секрет передаётся на один запуск и нигде не сохраняется.

Пока «Фоновый режим» выключен, окно держит туннели само, как раньше.
