Если локальный порт занят другой программой, Норка объясняет это своими словами и предлагает другой порт.

## Исправлено

- **Занятый локальный порт.** Когда порт держит не туннель Norka, а другая программа — часто Docker на порту 3000, — сверху показывается подсказка: смените локальный порт, например на 13000, и открывайте http://localhost:13000. Удалённый порт можно оставить прежним. Текст ошибки системы остаётся ниже, под «Техническая подробность». Если тот же порт занят другим туннелем Norka, по-прежнему предлагается «Подключить вместо». Подсказка на языке интерфейса. В компактном окне она короче и начинается с номера порта, чтобы он не обрезался.

## Документация

- Фоновый режим описан в `docs/BACKGROUND.md`. Окно подключается к `norkad`; в CLI и README больше не сказано, что окно в фон не уходит.
- В README — короткий ролик: обзор, цепочка jump host, туннели и переход в простой режим.

## Техническое

- Образцы winget, Scoop и Homebrew в `packaging/` этот выпуск не меняет. После тега `v1.6.1` задача `release` в `build.yml` вызывает workflow `update-manifests`: он берёт версию и хеши из `SHA256SUMS` и открывает отдельный pull request.

## Как обновиться

- **С 1.6.0:** на Windows и macOS нажмите «Обновить и перезапустить». На Linux кнопка «Скачать» открывает ссылку в браузере: программа сама себя не заменяет.
- **Windows:** если обновление в один клик недоступно, закройте Norka и замените старый `norka.exe` новым.
- **macOS:** откройте `norka.dmg` и перетащите Norka в «Программы» с заменой.
- **Linux:** скачайте AppImage, `.deb` или `.tar.gz`, что вам удобнее.

Туннели и настройки сохраняются.

## English

If another program already holds the local port, Norka says so in plain language and suggests a different one.

## Fixed

- **Local port already in use.** When the port is held by something other than a Norka tunnel — often Docker on port 3000 — a hint appears above the system error: change the local port, for example to 13000, and open http://localhost:13000. The remote port can stay as it is. The operating-system text stays below, under “Technical detail”. If another Norka tunnel holds the same port, “Connect instead” is still offered. The hint follows the interface language. In the compact window it is shorter and leads with the port number, so the number is not cut off.

## Documentation

- Background mode is described in `docs/BACKGROUND.md`. The window attaches to `norkad`; the CLI and README no longer say the window cannot move to the background.
- The README now has a short clip: overview, a jump-host chain, tunnels, and the switch to simple mode.

## Technical

- The winget, Scoop, and Homebrew samples in `packaging/` are unchanged in this release. After the `v1.6.1` tag, the `release` job in `build.yml` calls the `update-manifests` workflow: it takes the version and hashes from `SHA256SUMS` and opens a separate pull request.

## How to update

- **From 1.6.0:** on Windows and macOS press “Update and restart”. On Linux, “Download” opens the file in the browser: the app does not replace itself.
- **Windows:** if the one-click update is unavailable, quit Norka and replace the old `norka.exe`.
- **macOS:** open `norka.dmg` and drag Norka into Applications, replacing the previous copy.
- **Linux:** download the AppImage, `.deb`, or `.tar.gz`, whichever you prefer.

Tunnels and settings are kept.
