Если туннель не поднимается, Norka проверяет сеть до подключения. Из терминала туннелями можно управлять отдельным клиентом `norka-cli`.

## Новое

- **Проверка туннеля.** Пункт «Проверка туннеля» в меню «⋯» и кнопка в простом режиме смотрят DNS, порт jump-сервера, вход по ключу и свободный локальный порт. Пароль не отправляется, результат не сохраняется. Переключатель «Проверка туннеля» в Настройки → Функции, по умолчанию включён.
- **Клиент `norka-cli`.** Тонкая программа без окна: `connect`, `disconnect`, `toggle`, `status` и `list`. Чтобы команды доходили до туннелей, в Настройки → Функции включите «Автоматизация». Если Norka не запущена, `norka-cli connect` стартует её в трее.

Поставить клиент:

```bash
brew install norka-app/tap/norka-cli
```

```bash
scoop bucket add norka https://github.com/norka-app/scoop-bucket
scoop install norka-cli
```

```bash
go install github.com/norka-app/Norka/cmd/norka-cli@latest
```

Пакеты deb и rpm лежат в том же выпуске: `norka-cli_<версия>_linux_<архитектура>.deb` и `.rpm`.

- **Проверка файлов.** Убедиться, что файл собран в этом репозитории:

```bash
gh attestation verify norka.exe --repo norka-app/Norka
```

Та же команда подходит для архива, zip, deb и rpm: подставьте имя файла.

## Техническое

- Образцы winget, Scoop и Homebrew в `packaging/` этот выпуск не меняет. После тега `v1.5.0` задача `release` в `build.yml` вызывает workflow `update-manifests`: он берёт версию и хеши из `SHA256SUMS` и открывает отдельный pull request.

## Как обновиться

- **С 1.4.0:** на Windows и macOS нажмите «Обновить и перезапустить». На Linux кнопка «Скачать» открывает ссылку в браузере: программа сама себя не заменяет.
- **Windows:** если обновление в один клик недоступно, закройте Norka и замените старый `norka.exe` новым.
- **macOS:** откройте `norka.dmg` и перетащите Norka в «Программы» с заменой.
- **Linux:** скачайте AppImage, `.deb` или `.tar.gz`, что вам удобнее.

Туннели и настройки сохраняются.
